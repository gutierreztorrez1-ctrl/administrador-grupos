ADMINISTRADOR DE GRUPOS - VERSIÓN FINAL DE PRUEBA

1. Abre index.html con Microsoft Edge o Google Chrome.
2. La aplicación funciona sin instalar nada.
3. Los datos se guardan automáticamente en el navegador.
4. Usa "Copia de seguridad" para descargar todos los datos en JSON.
5. "Restaurar" permite volver a cargar esa copia.
6. En Informe mensual puedes imprimir o guardar como PDF y exportar CSV.

PUBLICACIÓN EN INTERNET
Esta versión es una aplicación estática (HTML/CSS/JavaScript), por lo que puede publicarse en GitHub Pages u otro hosting estático. GitHub Pages publica archivos HTML, CSS y JavaScript de un repositorio.

IMPORTANTE
La versión incluida guarda datos localmente en el navegador. Para que varias computadoras/celulares compartan una misma base de datos en tiempo real se necesita conectar una base de datos en la nube (por ejemplo Supabase/Firebase) y configurar autenticación. Esa parte requiere autorizar una cuenta/servicio y no debe hacerse con credenciales inventadas.
